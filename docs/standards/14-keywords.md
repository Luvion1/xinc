# 15. Keywords Reference

| Keyword | Description |
|---------|-------------|
| `_` | Wildcard pattern |
| `as` | Type coercion |
| `async` | Async function modifier |
| `await` | Await async computation |
| `break` | Exit loop |
| `const` | Compile-time constant |
| `continue` | Next loop iteration |
| `crate` | Current crate reference |
| `defer` | Deferred execution |
| `else` | Alternative branch |
| `enum` | Sum type definition |
| `err` | Error type alias |
| `export` | Public export |
| `extern` | External linkage |
| `false` | Boolean false |
| `fn` | Function definition |
| `for` | Iteration |
| `if` | Conditional |
| `impl` | Trait implementation |
| `in` | Iterator binding |
| `let` | Variable binding |
| `loop` | Infinite loop |
| `match` | Pattern matching |
| `mod` | Module declaration |
| `mut` | Mutable binding modifier |
| `pub` | Public visibility |
| `pub(crate)` | Crate-level visibility |
| `pub(super)` | Parent module visibility |
| `return` | Function return |
| `self` | Current instance |
| `Self` | Current type |
| `static` | Static lifetime |
| `struct` | Record type |
| `super` | Parent module |
| `trait` | Trait definition |
| `true` | Boolean true |
| `type` | Type alias |
| `use` | Import |
| `while` | While loop |
| `with` | Context manager |
| `yield` | Generator yield |
